# ✈️ Airport Insights Dashboard - Comprehensive Aviation Analytics

This project presents an interactive and comprehensive **Airport Insights Dashboard**, offering deep analytics into various aspects of aviation data across different U.S. states. The dashboard is designed to provide quick and actionable insights for aviation professionals and enthusiasts.

---

## ✨ Features & Analysis

* **Executive Overview (KPIs):** Key Performance Indicators (KPIs) providing a snapshot of critical aviation metrics.
* **Geographical Distribution:** Interactive maps visualizing airport distribution and key data points across various U.S. states (e.g., California, Texas, Florida, Alabama, Georgia).
* **Airport Type Analysis:** Breakdown of different airport types (Airport, Heliport, Seaplane Base) and their distribution.
* **State-wise Performance:** Detailed analysis of airport rates and performance per state, highlighting top-performing states like Texas with high airport rates.
* **Elevation Insights:** Information regarding airport elevations, identifying specific airports with notable characteristics (e.g., a Heliport in Colorado at high altitude vs. an Airport in California at low altitude).
* **Timeline History & Trends:** Visual representation of historical data points and trends over time (e.g., "timeline history of numbers").
* **Dynamic Theme Toggle:** Supports both Light and Dark modes for enhanced user experience (visible from screenshots).
* **Data Highlights:** Focus on specific data points like "PR airports" and their contribution to overall airport types.

---

## 📌 Data Source

The dashboard is built using the `داشبورد المطار.csv` dataset, which contains detailed information about various airports and their attributes.

## 🛠️ Tools & Technologies Used

* **Microsoft Excel**: Used as the primary tool for building this comprehensive and interactive dashboard.
* **Data Visualization**: Leveraging Excel's advanced charting and conditional formatting capabilities.
